# Taskbar Monitor

Windows 11 작업 표시줄 안에 CPU, 메모리, 디스크, 네트워크, GPU 사용량과 미니 그래프를 표시하는 가벼운 네이티브 위젯입니다.

> 현재 버전: **0.3.4 Beta**
>
> 개인 프로젝트로 개발 중인 초기 버전입니다. 주요 기능은 동작하지만 Windows 업데이트, 작업 표시줄 배치, 장치 드라이버에 따라 일부 기능이 다르게 동작할 수 있습니다.

## 화면

### 위젯 단독 모습

![CPU, RAM, DISK, NET, GPU 사용량과 미니 그래프](docs/widget-compact.png)

### Windows 11 작업 표시줄 안쪽 배치

![날씨 버튼과 시작·검색 버튼 사이에 배치된 Taskbar Monitor](docs/widget-taskbar.png)

위젯은 Windows 날씨 버튼과 시작 버튼의 실제 위치를 읽어 두 버튼 사이의 빈 공간에 맞춰집니다. `작업 표시줄 무배경 결합`을 사용하면 별도 패널처럼 보이지 않고 글자와 그래프만 표시됩니다.

## 주요 기능

- CPU, 메모리, 디스크, 네트워크, GPU를 개별적으로 표시하거나 숨길 수 있습니다.
- 각 항목의 숫자와 그래프를 서로 독립적으로 켜고 끌 수 있습니다.
- 표시 이름, 표시 순서, 색상, 그래프 형태를 항목별로 변경할 수 있습니다.
- 선, 채움, 막대 그래프를 지원합니다.
- 0.2~10초 갱신 간격과 10~600초 그래프 기록 시간을 선택할 수 있습니다.
- 작업 표시줄 안쪽 결합 모드와 작업 표시줄 위쪽 창 모드를 지원합니다.
- 전체화면에서 숨기기, 항상 표시, 표시하되 클릭 통과 중 하나를 선택할 수 있습니다.
- 위젯이 숨겨졌을 때 갱신을 5초로 늦춰 CPU 사용량을 줄일 수 있습니다.
- Windows 로그인 시 저장된 설정으로 자동 실행할 수 있습니다.
- 캡처 도구, 바탕화면, 일반 최대화 창을 전체화면 앱으로 잘못 판단하지 않도록 처리합니다.
- 검색·시작 메뉴가 열리면 Windows 기본 UI가 위젯보다 우선 표시됩니다.

## 마우스 조작

| 조작 | 동작 |
| --- | --- |
| 한 번 클릭 | 상세 그래프 열기/닫기 |

| 우클릭 | `위젯 설정 수정`, 상세 그래프, 표시/숨김, 일시정지, 작업 관리자, 종료 메뉴 |

## 설정 화면 설명

EXE를 직접 실행하거나 위젯을 우클릭한 뒤 `위젯 설정 수정`을 선택하면 설정창을 열 수 있습니다. 설정 항목 위에 마우스를 올리면 프로그램 안에서도 상세 설명이 표시됩니다.

### 표시 항목 표

| 설정 | 설명 |
| --- | --- |
| 표시 | 해당 측정 항목 전체를 위젯에 표시하거나 숨깁니다. |
| 항목 | CPU, 메모리, 디스크, 네트워크, GPU 중 측정 대상을 나타냅니다. |
| 표시 이름 | 위젯에 나타날 짧은 이름입니다. 셀을 클릭해 직접 수정할 수 있습니다. |
| 숫자 | 현재 사용률 또는 네트워크 전송 속도를 숫자로 표시합니다. |
| 그래프 | 설정한 기록 시간 동안의 변화 추이를 미니 그래프로 표시합니다. |
| 그래프 형태 | `선`은 가장 단순하고 가벼우며, `채움`은 변화량이 잘 보이고, `막대`는 순간값 비교에 적합합니다. |
| 색상 | 항목 이름과 그래프에 사용할 색상을 선택합니다. |

`전체 표시`, `모두 해제`, `그래프 전체`, `그래프 해제` 버튼으로 여러 항목을 한 번에 변경할 수 있습니다. `위로`, `아래로` 버튼은 작업 표시줄에 보이는 항목 순서를 변경합니다.

### 크기·동작·성능

| 설정 | 범위 / 권장값 | 설명 |
| --- | --- | --- |
| 갱신 간격 | 200~10000ms / **1000ms 권장** | 시스템 값을 다시 읽는 주기입니다. 낮을수록 빠르게 반응하지만 CPU 사용량이 늘 수 있습니다. |
| 그래프 기록 | 10~600초 / **60초 권장** | 미니 그래프가 보관할 과거 시간입니다. 길수록 변화 추이를 오래 볼 수 있고 메모리를 조금 더 사용합니다. |
| 최대 너비 | 160~1200px / 기본 560px | 위젯이 차지할 수 있는 최대 가로 폭입니다. 항목이 잘리면 늘리고 작업표시줄 공간이 부족하면 줄입니다. |
| 왼쪽 여백 | 0~1200px / 기본 126px | 작업 표시줄 왼쪽 끝을 기준으로 한 시작 위치 보정값입니다. 날씨·시작 버튼 사이 배치를 미세 조정할 때 사용합니다. |
| 투명도 | 25~100% / 기본 94% | 작업 표시줄 위쪽 창 모드의 패널 투명도를 조절합니다. 무배경 결합 모드에서는 영향이 적습니다. |
| 글꼴 크기 | 7~18 / 기본 9 | 항목 이름과 숫자의 글자 크기입니다. 칸이 좁을 때는 8~9가 보기 좋습니다. |
| 표시 위치 | 안쪽 / 위쪽 | `안쪽`은 실제 작업 표시줄의 자식 창으로 결합하고, `위쪽`은 작업 표시줄 바로 위에 독립 창으로 표시합니다. |
| 전체화면 동작 | 숨기기 / 항상 표시 / 클릭 통과 | 클릭 통과는 위젯을 보이게 유지하지만 마우스 입력을 전체화면 앱으로 전달합니다. |
| 내부 항목 폭 | 48~180px / 기본 70px | 안쪽 모드에서 CPU·RAM 같은 항목 하나가 차지할 기준 폭입니다. 좁으면 항목 이름이 축약될 수 있습니다. |
| 내부 높이 | 20~48px / 기본 28px | 작업 표시줄 안쪽 위젯의 높이입니다. 작업 표시줄 높이를 넘지 않도록 자동 제한됩니다. |

### 체크 옵션

| 옵션 | 설명 |
| --- | --- |
| 공간에 자동 맞춤 | 날씨 버튼과 시작 버튼 사이의 빈 공간에 맞춰 항목 폭을 자동으로 줄입니다. |
| 숨김 시 5초 절전 갱신 | 위젯이 보이지 않을 때 갱신 주기를 5초로 늦춰 자원 사용량을 줄입니다. |
| Windows 시작 시 자동 실행 | Windows 로그인 후 마지막으로 저장한 설정으로 위젯을 실행합니다. |
| 직접 실행 시 설정 먼저 표시 | EXE를 직접 실행했을 때 위젯보다 설정창을 먼저 엽니다. 자동 시작에는 적용되지 않습니다. |
| 작업 표시줄 무배경 결합 | 패널 배경과 외곽선을 투명 처리해 글자와 그래프만 작업 표시줄에 보이게 합니다. |

`적용`은 설정창을 유지한 채 현재 위젯에 반영합니다. `저장하고 표시 시작`은 설정을 저장하고 모니터링을 시작한 뒤 설정창을 닫습니다.

## 설치와 실행

### 소스에서 빌드

1. 저장소를 내려받거나 복제합니다.
2. PowerShell에서 저장소 폴더로 이동합니다.
3. 다음 명령을 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

빌드가 끝나면 `publish\TaskbarMonitor.exe`가 생성됩니다. Windows에 포함된 .NET Framework C# 컴파일러를 사용하므로 별도 Python 또는 .NET SDK는 필요하지 않습니다.

### 실행

`publish\TaskbarMonitor.exe`를 실행합니다. 기본 설정에서는 직접 실행할 때 설정창이 먼저 열립니다. 관리자 권한은 필요하지 않습니다.

설정 파일은 다음 위치에 저장됩니다.

```text
%LOCALAPPDATA%\TaskbarMonitor\settings.json
```

## 성능과 개인정보

- 권장 갱신 간격은 1000ms입니다. 더 빠른 200~500ms 갱신은 그래프가 부드러워지는 대신 CPU 사용량이 증가할 수 있습니다.
- 숨김 절전 갱신을 켜면 보이지 않을 때 5초에 한 번만 측정합니다.
- 모든 측정과 설정 저장은 PC 내부에서 처리됩니다.
- 네트워크 서버, 계정, 광고, 원격 분석 기능을 사용하지 않습니다.
- 관리자 권한 없이 실행되도록 설계했습니다.

## 온도 표시 지원

현재 0.3.4는 사용률만 표시하며 CPU·GPU 온도는 표시하지 않습니다.

- NVIDIA GPU 온도는 `nvidia-smi`와 같은 드라이버 도구를 통해 추가할 수 있습니다.
- CPU 온도는 Windows 표준 성능 카운터만으로 안정적으로 읽기 어렵습니다.
- CPU 온도를 지원하려면 LibreHardwareMonitor 같은 센서 라이브러리, 장치별 처리, 경우에 따라 관리자 권한이 필요합니다.

향후에는 `GPU 온도`를 선택 항목으로 추가하고, CPU 온도는 센서를 읽을 수 있는 PC에서만 표시하는 방식을 검토하고 있습니다.

## 알려진 제한 사항

- 현재는 Windows 11의 기본 가로형 작업 표시줄과 주 모니터 환경을 기준으로 개발·테스트했습니다.
- 작업 표시줄 위치나 구조가 Windows 업데이트로 변경되면 배치 보정이 필요할 수 있습니다.
- GPU 사용률은 그래픽 드라이버와 Windows 성능 카운터 지원 상태에 따라 0%로 표시될 수 있습니다.
- 사용자 지정 작업 표시줄 프로그램이나 셸 대체 프로그램과의 호환성은 보장하지 않습니다.
- 설치 프로그램과 자동 업데이트 기능은 아직 없습니다.

## 개발 상태와 공개 안내

이 프로젝트는 **Beta 단계의 개인 프로젝트**입니다. 완성도가 100%가 아니어도 GitHub에 공개할 수 있으며, 오히려 현재 상태와 제한 사항을 명확히 적어두면 사용자 피드백을 받는 데 도움이 됩니다.

공개할 때는 다음을 권장합니다.

- 저장소 설명과 README에 `Beta`, `개발 중`, `Windows 11 테스트`를 명시합니다.
- GitHub Issues에 버그 신고 양식을 준비합니다.
- 실행 파일은 GitHub Releases에 버전별로 올리고 SHA-256 값을 함께 제공합니다.
- 다른 사람이 코드와 실행 파일을 사용할 수 있도록 공개 전 라이선스를 선택합니다.
- 안정 버전이 나오기 전까지는 `v0.x` 버전을 유지합니다.

현재 저장소가 비공개라면 먼저 충분히 테스트한 뒤 공개로 전환해도 됩니다. 비공개 저장소에 코드를 올리는 것은 현재 PC에서 실행 중인 위젯이나 로컬 프로젝트에 영향을 주지 않습니다.

## 변경 기록

### 0.3.4

- 설정창이 생성됐지만 다른 모니터에 열려 보이지 않던 문제를 수정했습니다.
- 설정 메뉴를 누른 마우스가 있는 모니터의 작업 영역 중앙으로 설정창을 이동합니다.
- 이미 열린 설정창도 다시 호출하면 현재 모니터로 가져오도록 개선했습니다.

### 0.3.3

- 작업 표시줄 안쪽 우클릭 메뉴에서 `위젯 설정 수정`을 눌러도 설정창이 열리지 않던 문제를 수정했습니다.
- 메뉴가 완전히 닫힌 뒤 설정창을 열고 전면으로 가져오도록 호출 순서를 개선했습니다.
- 실행 중인 EXE를 다시 실행해도 기존 위젯의 설정창이 열리도록 단일 인스턴스 메시지 대상을 보강했습니다.

### 0.3.2

- 작업 표시줄 안쪽 위젯의 우클릭 메뉴를 명시적으로 열어 반응을 안정화했습니다.
- 우클릭 메뉴의 첫 항목을 `위젯 설정 수정`으로 명확하게 변경했습니다.
- 설정창에 권장값, 성능 영향, 각 옵션의 상세 도움말을 추가했습니다.

### 0.3.1

- 바탕화면의 `Progman/WorkerW` 창을 전체화면 앱으로 오인해 위젯이 숨겨지던 문제를 수정했습니다.
- 기본·보조 작업 표시줄 창을 전체화면 판정에서 제외했습니다.

### 0.3

- 작업 표시줄과 다른 색으로 보이던 패널 배경과 외곽선을 제거했습니다.
- 내부 위젯을 28px 높이로 축소하고 네트워크 단위를 간결하게 표시했습니다.
- Windows 날씨·시작 버튼의 실제 위치를 감지해 빈 공간에 자동 배치하도록 변경했습니다.
- 항목 폭과 내부 높이를 설정 화면에서 직접 조절할 수 있게 했습니다.

### 0.2

- 일반 최대화 창을 전체화면으로 잘못 판정해 위젯이 사라지던 문제를 수정했습니다.
- 캡처 도구 실행 중 위젯이 사라지던 문제를 수정했습니다.
- 작업 표시줄 안쪽 표시를 최상위 오버레이에서 실제 작업 표시줄 자식 창 방식으로 변경했습니다.
- 검색 및 시작 메뉴가 위젯 아래에 가려지지 않도록 창 계층을 수정했습니다.
