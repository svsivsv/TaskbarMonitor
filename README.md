# Taskbar Monitor

Windows 작업 표시줄에 CPU, 메모리, 디스크, 네트워크, GPU 사용량과 미니 그래프를 표시하는 가벼운 네이티브 앱입니다.

현재 버전: **0.3.1**

## 실행

`publish\TaskbarMonitor.exe`를 실행합니다. 기본 설정에서는 실행할 때마다 항목 선택 화면이 먼저 열립니다.

- 한 번 클릭: 상세 그래프 열기/닫기
- 더블클릭: 작업 관리자 열기
- 우클릭: 설정, 일시정지, 작업 관리자, 종료
- 트레이 아이콘 왼쪽 클릭: 상세 그래프 열기/닫기

## 주요 설정

- CPU, 메모리, 디스크, 네트워크, GPU를 개별 선택
- 항목별 숫자와 그래프를 각각 선택
- 선, 채움, 막대 그래프 및 항목별 색상
- 0.2~10초 갱신 간격과 10~600초 그래프 기록
- 작업 표시줄 안쪽/위쪽 위치, 최대 너비, 왼쪽 여백, 투명도, 글꼴
- 전체화면에서 숨기기/항상 표시/클릭 통과
- 작업 표시줄 안쪽 모드에서는 위젯을 작업 표시줄의 실제 자식 창으로 결합
- 내부 모드 기본 높이 28px, 항목 폭 70px의 무배경 표시
- 날씨 버튼과 시작 버튼 위치를 읽어 두 버튼 사이의 실제 빈 공간에 자동 맞춤
- 캡처 도구는 전체화면으로 오인하지 않으며 검색·시작 메뉴가 위젯보다 우선 표시
- Windows 시작 시 저장된 설정으로 자동 실행

설정은 `%LOCALAPPDATA%\TaskbarMonitor\settings.json`에 저장됩니다. 관리자 권한은 필요하지 않습니다.

## 빌드

PowerShell에서 다음 명령을 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Windows 기본 .NET Framework 컴파일러를 사용하므로 별도 Python 또는 .NET SDK가 필요하지 않습니다.

## 변경 기록

### 0.3.1

- 바탕화면의 `Progman/WorkerW` 창을 전체화면 앱으로 오인해 위젯이 숨겨지던 문제 수정
- 기본·보조 작업 표시줄 창을 전체화면 판정에서 제외

### 0.3

- 작업 표시줄과 다른 색으로 보이던 패널 배경 및 외곽선 제거
- 내부 위젯을 28px 높이로 축소하고 네트워크 단위를 간결하게 표시
- Windows 날씨·시작 버튼의 실제 위치를 감지해 빈 공간에 자동 배치
- 항목 폭과 내부 높이를 설정 화면에서 직접 조절 가능

### 0.2

- 일반 최대화 창을 전체화면으로 잘못 판정해 위젯이 사라지던 문제 수정
- 캡처 도구 실행 중 위젯이 사라지던 문제 수정
- 작업 표시줄 안쪽 표시를 최상위 오버레이에서 실제 작업 표시줄 자식 창 방식으로 변경
- 검색 및 시작 메뉴가 위젯 아래에 가려지지 않도록 창 계층 수정
